# Trivia App MVP 

## Overview
This project is a Minimum Viable Product (MVP) trivia application. The goal was to design, implement, and validate core backend functionality using structured project management practices, GitHub issue tracking, and milestone-based goals.
The application supports creating, managing, searching, and participating in trivia questions while tracking user scores and rankings.

## Tech Stack
- JavaScript (Node.js)
- REST APIs
- Message Queues (MQ)
- GitHub Issues & Milestones
- Automated Testing

## Key Features
- Question creation (manual + API)
- Edit & search functionality
- Admin & user endpoints
- Quiz participation and scoring
- Score history and ranking
